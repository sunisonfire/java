Repositorio con mis apuntes y ejercicios de las clases de programación en Java.

## 🔍 Cómo buscar un archivo

**Opción 1: Índice de este README**
Usa la tabla de abajo. Está organizada por tema y fecha, con enlaces directos a cada archivo.

**Opción 2: Buscador de GitHub**
En cualquier página del repo, presiona la tecla `T` (o haz clic en "Go to file") y escribe el nombre del archivo o tema. GitHub filtra en tiempo real.

## ➕ Cómo mantener este índice actualizado

Cada vez que agregues un archivo nuevo:

1. Usa un nombre consistente: `TEMA (dd-mm-aa).md`
2. Agrega una fila nueva a la tabla de arriba, con el enlace en formato:
   ```
   [NOMBRE EXACTO DEL ARCHIVO](./NOMBRE%20EXACTO%20DEL%20ARCHIVO.md)
   ```
   (Los espacios en el link se escriben como `%20`)
3. Ordena la tabla por fecha o por tema, como prefieras.
